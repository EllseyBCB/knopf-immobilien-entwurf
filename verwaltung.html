Knopf Immobilien — Anfragen

Diese Seite ist fertig, aber noch mit keiner Datenbank verbunden. Es fehlen zwei Angaben aus dem Supabase-Projekt. Sie stehen dort unter Project Settings → API.

  1. In verwaltung.js ganz oben SUPABASE_URL eintragen
  2. Darunter SUPABASE_SCHLUESSEL eintragen (der öffentliche Schlüssel)
  3. Im SQL-Editor einmal schema.sql ausführen
  4. Unter Authentication → URL Configuration die Adresse dieser Seite als erlaubtes Ziel eintragen

Der öffentliche Schlüssel darf in dieser Datei stehen — er allein gibt keinen Zugriff auf die Anfragen. Dafür sorgen die Zugriffsregeln in der Datenbank.
